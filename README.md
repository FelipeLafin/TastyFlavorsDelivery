# 🍔📦 **Tasty Flavors** – Delivery de Sabor na Sua Mão!

Bem-vindo ao **Tasty Flavors**, um aplicativo de delivery moderno e rápido, feito com 💖 usando **Python**, **HTML**, **CSS** e **JavaScript**!  
Com uma interface amigável e um backend robusto, o Tasty Flavors é a solução ideal para pedidos de comida online. 😋

---

## 🚀 Funcionalidades

✅ Cadastro e login de usuários  
✅ Catálogo de restaurantes e pratos 🍕🍔    
✅ Carrinho de compras com checkout 🛒 (Em progresso)   
✅ Painel de administração (Em progresso)   
✅ Notificações e status de pedidos em tempo real 🔔 (Em progresso)   
✅ Interface responsiva para dispositivos móveis 📱

---

## 🧰 Tecnologias Usadas

### Backend
- 🐍 Python (Flask / Django / FastAPI)
- 💾 SQLite / PostgreSQL
- 🔐 Autenticação com JWT ou sessões

### Frontend
- 🌐 HTML5
- 🎨 CSS3 (ou TailwindCSS / Bootstrap)
- ⚡ JavaScript (vanilla ou com frameworks)

## 🛠️ Como Rodar o Projeto Localmente

1. Clone este repositório:
   ```bash
   git clone https://github.com/FelipeLafin/TastyFlavorsDelivery.git
   cd TastyFlavorsDelivery
   ```
2. Crie um ambiente virtual:
   ```bash
   python -m .venv venv
   source .venv/bin/activate      # Linux/macOS
   .venv\Scripts\activate         # Windows
   ```
3. Instale as dependencias:
    ```bash
    pip install -r requirements.txt
    ```
4. Inicie o app:
   ```bash
   python3 main.py
   ```
